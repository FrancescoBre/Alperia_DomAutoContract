CABONA - Compilatore Contratti Alperia
======================================

INSTALLAZIONE:
1. Assicurati di avere Python 3.8+ installato
2. Apri il terminale in questa cartella
3. Esegui: pip install flask pypdf
4. Esegui: python app.py
5. Apri il browser su: http://localhost:7860

USO:
- Seleziona Luce e/o Gas
- Compila i dati del cliente
- Premi "Genera PDF" per scaricare il contratto compilato
- Solo i campi firma rimarranno vuoti

AGGIORNAMENTO OFFERTE:
- Modifica la lista OFFERTE_LUCE e OFFERTE_GAS in app.py
